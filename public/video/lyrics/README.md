# 자막(.lrc) 넣는 법

렌더러는 이 폴더의 `.lrc` 파일을 읽어 자막을 그립니다.
`video.project.json` 의 `lyrics.lrcSrc` 가 가리키는 파일이 사용됩니다.

```json
"lyrics": { "lrcSrc": "video/lyrics/photograph.lrc" }
```

> 가사 텍스트가 든 `.lrc` 는 `.gitignore` 처리되어 있습니다. 이 저장소는
> GitHub Pages로 공개 배포되므로 원곡 가사·음원이 그대로 올라가지 않게 해뒀습니다.
> 로컬에 파일만 두면 렌더는 정상 동작합니다.

---

## 방법 A — 스튜디오에서 직접 타이밍 찍기 (권장)

가장 정확하고, 이 프로젝트에 맞춰 만든 방식입니다.

```bash
npm run dev
```

→ `http://localhost:5173/Wedding/#/studio` → **가사** 탭

1. **출력** 탭에서 음원 경로를 `music/photograph.mp3` 로 맞춥니다.
2. **가사** 탭 맨 위 텍스트 상자에 가사를 **한 줄씩** 붙여넣습니다.
   - 2개 국어로 할 거면 원문 줄과 번역 줄을 **번갈아** 붙여넣으세요.
     ```
     (원문 1행)
     (번역 1행)
     (원문 2행)
     (번역 2행)
     ```
3. `줄 목록 만들기` 를 누르면 아래에 줄 목록이 생깁니다. (타이밍은 아직 임시)
4. `▶ 재생` 을 누르고, **각 줄이 시작되는 순간** 그 줄의 `지금` 버튼을 클릭합니다.
   - 원문/번역 쌍은 **같은 시각**을 찍어야 위아래로 묶입니다.
     원문 줄에 `지금` 을 찍고, 바로 아래 번역 줄에도 한 번 더 찍으면 됩니다.
     (0.06초 이내면 한 쌍으로 인식)
5. 어긋난 줄은 `◀ ▶` 로 0.1초씩 밀고 당깁니다.
6. 전체가 일정하게 밀렸으면 맨 아래 `전체 오프셋` 슬라이더로 한 번에 보정합니다.
7. `.lrc 내보내기` → 받은 파일을 `public/video/lyrics/photograph.lrc` 로 저장.

미리보기가 최종 mp4와 같은 엔진이라, 스튜디오에서 맞으면 렌더 결과도 맞습니다.

---

## 방법 B — 이미 있는 .lrc 파일 쓰기

싱크가 들어간 `.lrc` 를 이미 갖고 계시면 그대로 넣으면 됩니다.

1. `public/video/lyrics/photograph.lrc` 로 저장
2. 스튜디오 **가사** 탭 → `.lrc 파일` 버튼으로 불러와 싱크 확인
3. 어긋나면 `전체 오프셋` 으로 보정 후 다시 내보내기

한국어 번역을 덧붙이려면, 원문 줄 바로 아래에 **같은 타임스탬프**로 번역 줄을 추가하면 됩니다.

## .lrc 문법

```lrc
[00:12.40]원문 한 줄
[00:12.40]같은 시각에 한 줄 더 두면 → 위=원문, 아래=번역
[00:18.90]다음 줄
[00:24.00]                    ← 텍스트 없는 줄 = 간주 구간
[offset:-300]                 ← 전체 자막 300ms 앞당기기
```

단어별 하이라이트(가라오케)를 쓰려면:

```lrc
[00:30.00]<00:30.0>단어 <00:30.7>단위로 <00:31.6>강조
```

## 자막 표시 설정

스튜디오 탭에서 조절합니다.

| 탭 | 조절 항목 |
|---|---|
| **2개 국어** | 원문/번역 순서, 번역 글자 크기·투명도·줄 간격, 원문 서체·자간 |
| **자막 스타일** | 글자 크기, 위치, 색, 등장 애니메이션, 그림자, 가라오케 색 |
| **구조** | 가사 패널 크기 (Duplex의 `사진 높이` 를 줄이면 패널이 커짐) |

Duplex 가로배치 기준 패널이 282px라 **원문 1줄 + 번역 1줄**이 적정합니다.
한 줄이 길어 두 줄로 접히면 패널을 넘칠 수 있으니, 긴 문장은 `.lrc` 에서
직접 두 줄로 나눠 각각 타임스탬프를 주는 편이 깔끔합니다.
